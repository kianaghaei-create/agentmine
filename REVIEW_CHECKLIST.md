# Weekly and milestone review checklist

- [ ] Read PROJECT_MEMORY.md, NORTH_STAR.md, CURRENT_EXPERIMENT.md, ROADMAP.md, DECISION_LOG.md and current GitHub issue.
- [ ] Record what was built, what was observed, and what remains unverified.
- [ ] Update evidence table with sources, timestamps and confidence.
- [ ] Review actual revenue, costs, leads, conversions, recurring usage and hours spent (mark N/A if none).
- [ ] Challenge the current thesis and identify at least one unconventional alternative.
- [ ] Decide continue / pivot / stop and explain why.
- [ ] Update CURRENT_EXPERIMENT.md and PROJECT_MEMORY.md; append decisions to DECISION_LOG.md.
- [ ] Open or update GitHub issue for next measurable milestone.
- [ ] Commit changes; do not claim the memory was updated without a commit.
